# Sadakat programı: ilk konuşma

Selin: Sadakat puanlarını yenileyelim. Kullanıcılar puanların ne işe yaradığını anlamıyor.

Mert: Teknik olarak puanlar ayrı bir serviste duruyor. Değişiklik o ekibe gider.

Selin: Rakipler daha cömert puan veriyor diye duydum.

Mert: Hangi rakip? Elimizde veri var mı?

Selin: Yok, sadece duydum.
